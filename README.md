# TBH-ParamFinder - Bug Bounty Hidden Parameter Finder

<p align="center"><img src="https://img.shields.io/badge/Bug%20Bounty-ParamFinder-red?style=for-the-badge"></p>

> **Hanya untuk scope yang diizinkan.** Cari hidden parameter untuk test IDOR/XSS.

## ✨ Features
- Cari `?id=`, `?debug=`, `?admin=` di HTML/JS
- JSON export

## 🚀 Usage
```bash
git clone https://github.com/TulungagungBlackHat/TBH-ParamFinder
python3 paramfinder.py -u https://example.com --json out.json
```
